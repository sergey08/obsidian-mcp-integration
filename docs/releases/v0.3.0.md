## English

First stable release of Obsidian MCP as a Home Assistant integration. It provides nine tools for Markdown notes, revision-aware edits and recoverable deletion. Use an existing local vault under `/share` or synchronize with CouchDB through Self-hosted LiveSync. The private OpenAI tunnel and optional Bearer-authenticated MCP endpoint are configured independently.

The README covers both modes, setup, diagnostics and migration from the Home Assistant app. AMD64 and ARM64 LiveSync bundles for Alpine-based Home Assistant Core are attached with SHA-256 checksums.

Existing beta users can update the integration through HACS. Existing installations that use the Home Assistant app should follow the migration procedure before enabling LiveSync or reusing a tunnel ID in the integration.

## Español

Primera versión estable de Obsidian MCP como integración de Home Assistant. Incluye nueve herramientas para notas Markdown, edición con control de revisiones y borrado recuperable. Puedes usar una bóveda local existente dentro de `/share` o sincronizar con CouchDB mediante Self-hosted LiveSync. El túnel privado de OpenAI y el acceso MCP opcional con token Bearer se configuran por separado.

El README explica los dos modos, el diagnóstico y la migración desde la aplicación. Se adjuntan los paquetes LiveSync AMD64 y ARM64 para Home Assistant Core sobre Alpine y sus sumas SHA-256.

Si ya usas la beta, puedes actualizar la integración desde HACS. Si usas la aplicación anterior, sigue la guía de migración antes de activar LiveSync o de reutilizar el mismo ID de túnel.
