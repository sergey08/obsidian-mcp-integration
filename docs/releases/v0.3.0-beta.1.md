## English

First test release of the Obsidian MCP integration for Home Assistant. It preserves the existing nine MCP tools, revision checks, recoverable trash, LiveSync, the private OpenAI tunnel and optional authenticated remote access. It is configured via Settings → Devices & services.

Install as a custom HACS integration. LiveSync runtimes and SHA-256 checksums for AMD64 and ARM64 are attached for Home Assistant Core on Alpine. Start with a test vault and see the README for migration and rollback.

## Español

Primera beta de la integración Obsidian MCP para Home Assistant. Conserva las nueve herramientas MCP, el control de revisiones, la papelera recuperable, LiveSync, el túnel privado de OpenAI y el acceso remoto autenticado opcional. Se configura desde Ajustes → Dispositivos y servicios.

Instálala como integración personalizada en HACS. Se adjuntan los paquetes LiveSync y sus sumas SHA-256 para AMD64 y ARM64 en Home Assistant Core sobre Alpine. Empieza con una bóveda de prueba y consulta el README para migrar o revertir.
