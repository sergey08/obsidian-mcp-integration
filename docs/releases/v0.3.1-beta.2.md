# Obsidian MCP v0.3.1-beta.2

## English

Based on the v0.3.0 stable integration. All nine MCP tools now report explicit read-only, destructive, idempotency and open-world hints in `tools/list`. Clients can use these hints to show users how a tool affects the vault. Existing note operations and their arguments keep the same behavior.

Enable beta versions in HACS and select **v0.3.1-beta.2**. Restart Home Assistant if prompted.

## Español

Basada en la integración estable v0.3.0. Las nueve herramientas MCP publican en `tools/list` indicadores explícitos de solo lectura, cambios destructivos, idempotencia e interacción con sistemas externos. Los clientes pueden usarlos para indicar a los usuarios cómo afecta cada herramienta a la bóveda. Las operaciones sobre notas y sus argumentos conservan su comportamiento.

Activa las versiones beta en HACS y selecciona **v0.3.1-beta.2**. Reinicia Home Assistant si te lo pide.
