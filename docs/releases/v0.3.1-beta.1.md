## English

This prerelease adds an opt-in, Bearer-authenticated MCP listener on the Home Assistant host's loopback interface. Use SSH forwarding to try Claude Desktop and Grok Build alongside the existing OpenAI tunnel, without publishing the MCP endpoint.

Select **Show beta versions** in HACS and choose **v0.3.1-beta.1**. See **Private MCP for Claude Desktop and Grok Build (beta)** in the release's README. Use a disposable vault for the first test.

## Español

Esta beta añade un acceso MCP opcional, autenticado con un token Bearer y limitado a la interfaz local del host de Home Assistant. Usa un reenvío SSH para probar Claude Desktop y Grok Build junto al túnel de OpenAI sin publicar el endpoint MCP.

Activa **Mostrar versiones beta** en HACS y elige **v0.3.1-beta.1**. Consulta **MCP privado para Claude Desktop y Grok Build (beta)** en el README de la versión. Usa una bóveda temporal para la primera prueba.
