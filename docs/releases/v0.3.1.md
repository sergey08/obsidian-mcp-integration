# Obsidian MCP v0.3.1

## English

All nine MCP tools now return explicit read-only, destructive, idempotency and open-world hints in `tools/list`. Clients can use them to distinguish vault queries from actions, warn about changes and identify actions such as appending text that may duplicate content when retried.

Update Obsidian MCP from HACS / Marketplace and restart Home Assistant if prompted. Existing configurations need no migration.

## Español

Las nueve herramientas MCP devuelven en `tools/list` indicadores explícitos de solo lectura, cambios destructivos, idempotencia e interacción con sistemas externos. Los clientes pueden usarlos para distinguir las consultas de las acciones sobre la bóveda, advertir de los cambios e identificar operaciones que, como añadir texto, pueden duplicar contenido si se reintentan.

Actualiza Obsidian MCP desde HACS / Marketplace y reinicia Home Assistant si te lo pide. Las configuraciones existentes no requieren migración.
